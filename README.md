# 📮 POST Family AutoFill — ตัวช่วยกรอกข้อมูลสมัครสมาชิกอัตโนมัติ

> ส่วนขยาย (Extension) ของ Google Chrome ที่ช่วย **กรอกข้อมูลสมัครสมาชิก POST Family (ไปรษณีย์ไทย)** ให้โดยอัตโนมัติ
> คุณแค่เอารูปหรือข้อความที่มีข้อมูลมาให้ มันจะอ่านข้อมูลออกเอง แล้วช่วยกรอกลงเว็บให้เสร็จ ๆ ไปเลย ✨

---

## 🤔 เจ้านี่ช่วยอะไรได้บ้าง?

- 🖱️ **กดปุ่มเดียว** — มันเปิดหน้าสมัครให้เอง พร้อมติ๊ก "ยอมรับข้อตกลง" ให้เรียบร้อย
- 🧠 **อ่านข้อมูลเก่ง** — เอารูป (เช่น ภาพหน้าจอข้อมูล) หรือข้อความมาวาง มันใช้ AI (Gemini) อ่านชื่อ ที่อยู่ วันเกิด เบอร์โทร ออกมาให้เอง
- 📝 **ตรวจสอบก่อนกรอก** — ข้อมูลที่อ่านได้จะมาโชว์ให้คุณเช็กก่อน ผิดตรงไหนแก้ได้
- 🎁 **จำรหัสแนะนำ** — เก็บ "รหัสสมาชิกแนะนำ" กับ "รหัสไปรษณีย์แนะนำ" ไว้ใช้ซ้ำได้ ไม่ต้องพิมพ์บ่อย

---

## 📥 ขั้นตอนที่ 1 — เอาตัวโปรแกรมลงเครื่อง

> ไม่ต้องลงโปรแกรมอะไรเพิ่ม ไม่ต้องใช้คำสั่งคอมพิวเตอร์ แค่คลิก ๆ ก็เสร็จ ✅

1. เปิดลิงก์นี้ในเบราว์เซอร์:
   ```
   https://github.com/fiwflash/post-family-autofill
   ```

2. มองหาปุ่ม **สีเขียว** ที่เขียนว่า **`<> Code`** (อยู่มุมบนขวาของหน้านั้น) แล้วคลิกมัน

3. จะมีเมนูเด้งขึ้นมา ให้คลิกคำว่า **`Download ZIP`**

   ![ปุ่ม Download ZIP จะอยู่ในเมนูที่เด้งออกมา](https://docs.github.com/assets/cb-20363/images/help/repository/code-button.png)

4. ไฟล์ที่ชื่อประมาณ **`post-family-autofill-main.zip`** จะถูกโหลดลงเครื่อง (มักอยู่ในโฟลเดอร์ **ดาวน์โหลด / Downloads**)

5. ไปที่โฟลเดอร์ดาวน์โหลด แล้ว**คลิกขวา**ที่ไฟล์ `.zip` → เลือก **`Extract All…`** (หรือ **`แตกไฟล์ทั้งหมด…`**) แล้วกด **Extract / ตกลง**

   > 📌 ตอนนี้คุณจะได้โฟลเดอร์ชื่อ **`post-family-autofill-main`** — จำไว้ว่ามันอยู่ตรงไหน เราต้องใช้ในขั้นตอนต่อไป

---

## 🌐 ขั้นตอนที่ 2 — ใส่ลงใน Google Chrome

1. เปิดโปรแกรม **Google Chrome**

2. พิมพ์ข้อความนี้ลงในช่องที่อยู่ด้านบน (แล้วกด Enter):
   ```
   chrome://extensions/
   ```

3. มองมุมขวาบนของหน้านั้น จะมีสวิตช์ **`Developer mode`** (โหมดนักพัฒนา) — **เปิดมัน** (เลื่อนให้เป็นสีฟ้า)

4. พอเปิดแล้ว จะมีปุ่มใหม่โผล่ขึ้นมา 3 ปุ่ม ให้คลิกปุ่ม **`Load unpacked`** (โหลดส่วนขยายที่ยังไม่ได้แพ็ก)

5. จะมีหน้าต่างเลือกโฟลเดอร์เด้งขึ้นมา ให้**เลือกโฟลเดอร์ `post-family-autofill-main`** ที่เราแตกไฟล์ไว้ในขั้นตอนที่ 1 แล้วกด **Select Folder / เลือกโฟลเดอร์**

   > ⚠️ ต้องเลือก**ตัวโฟลเดอร์** (เข้าไปข้างในแล้วกดเลือก) ไม่ใช่ตัวไฟล์ `.zip`

6. เสร็จแล้ว! จะเห็นการ์ดชื่อ **`POST Family AutoFill`** โผล่ขึ้นมาในรายการ = ติดตั้งสำเร็จ 🎉

## 🔑 ขั้นตอนที่ 3 — ขอกุญแจ AI (Gemini API Key)

ตัวโปรแกรมต้องใช้ "กุญแจ" ฟรีจาก Google ถึงจะอ่านข้อมูลให้ได้ ขอได้ไม่กี่นาที:

1. เปิดลิงก์นี้:
   ```
   https://aistudio.google.com/
   ```

2. **ลงชื่อเข้าใช้**ด้วยบัญชี Google ของคุณ (ถ้ายังไม่เคยเข้า)

3. มองหาเมนู **`Get API key`** หรือ **`Create API key`** แล้วคลิก → ทำตามที่หน้าเว็บแนะนำ

4. จะได้ข้อความยาว ๆ คล้าย ๆ นี้ (ตัวอักษรกับตัวเลขผสมกัน):
   ```
   AIzaSy...
   ```
   → **กด Copy / คัดลอก**เก็บไว้ให้ดี (อันนี้คือ "กุญแจ" ของคุณ อย่าให้คนอื่น)

## 🚀 ขั้นตอนที่ 4 — เริ่มใช้งานจริง

### 4.1 เปิดหน้าต่างควบคุม

- คลิกไอคอน **รูปชิ้นส่วนจิ๊กซอว์ 🧩** มุมขวาบนของ Chrome (ถ้าไม่เห็น ให้กด `...` → `Extensions`)
- คลิกชื่อ **`POST Family AutoFill`** → หน้าต่างควบคุมจะเด้งออกมาทางขวา

### 4.2 ใส่กุญแจ AI

- วาง (วางด้วย `Ctrl + V`) กุญแจ API ที่ได้จากขั้นตอนที่ 3 ลงในช่อง **API Key**
- รอสักครู่ จะเห็นจุดสีเขียว = ใช้ได้แล้ว

### 4.3 เริ่มกรอกข้อมูล (เรียงตามลำดับเลย)

| ขั้นตอน | ปุ่มที่กด | มันทำอะไรให้ |
|---|---|---|
| 1️⃣ | **📑 เปิดเว็บ & กดยอมรับข้อตกลง (Step 1)** | เปิดหน้าสมัคร แล้วกดยอมรับเงื่อนไขให้เอง |
| 2️⃣ | ช่อง **"ข้อมูลนำเข้า"** → วางรูป (`Ctrl+V`) หรือพิมพ์ข้อความ → กด **✨ วิเคราะห์ข้อมูล** | AI อ่านข้อมูลออกมาโชว์ให้เช็ก |
| 3️⃣ | เช็กข้อมูลให้ถูก → กด **🔵 กรอกข้อมูล Step 2** | กรอกชื่อ วันเกิด เบอร์โทร รหัสแนะนำ ฯลฯ |
| 4️⃣ | กด **🟢 กรอกข้อมูล Step 3** | เลือกจังหวัด อำเภอ ตำบล และกรอกที่อยู่ให้ |

> 💡 **Tip:** กด `Ctrl + V` ลงในช่อง "ข้อมูลนำเข้า" ได้เลยถ้าเป็นรูป (เหมือนแปะรูปในแชท)

## 🆘 เจอปัญหา? ลองทำแบบนี้

**❓ หน้า `chrome://extensions/` ไม่เห็นปุ่ม Load unpacked**
→ ยังไม่ได้เปิด **Developer mode** กลับไปเปิดสวิตช์ที่มุมขวาบนก่อน

**❓ กดปุ่มแล้วมันบอก "กรุณาเปิดหน้าเว็บ POST Family ก่อน"**
→ ต้องกด **Step 1** ก่อน เพื่อเปิดหน้าสมัครขึ้นมาก่อนเสมอ

**❓ วิเคราะห์แล้วขึ้น "API Key ผิดพลาด" หรือจุดแดง**
→ กุญแจอาจวางไม่ครบ/ผิดตัว ลอง Copy ใหม่จาก Google AI Studio แล้ววางใหม่

**❓ ข้อมูลกรอกผิดเพี้ยน**
→ AI อาจอ่านพลาด กลับไปเช็กในหน้าตรวจสอบแล้วแก้เองก่อนกดกรอกได้เลย

**❓ เปลี่ยนโปรแกรมแล้วยังใช้ไม่ได้**
→ ปิดหน้าเว็บ POST Family แล้วเปิดใหม่ (รีเฟรช) บางครั้งต้องรีเฟรชถึงจะโหลดตัวโปรแกรมใหม่

## 📝 หมายเหตุ

- ควรใช้**เฉพาะรูปหรือข้อความที่มีข้อมูลสำหรับสมัคร POST Family** เท่านั้น
- ต้องมี **Gemini API Key** (ขอฟรีได้จาก [Google AI Studio](https://aistudio.google.com/))
- โปรแกรมนี้เก็บกุญแจ API ไว้ในเครื่องคุณเอง ไม่ส่งไปที่อื่น

- **Google Gemini API** (วิเคราะห์ข้อมูลผ่าน REST API)
- **HTML5 / CSS3 / Vanilla JavaScript** (ไม่ต้องลงอะไรเพิ่ม)
